The point of the experiment

A representation can be useful without already being a world model.

Patch features can support retrieval, grouping, and boundaries. The moment we say two regions are the same object, adjacent, near, or semantically similar, we have made a new claim. The public artifact keeps those steps separate so each one can be inspected.
