| Model | Identifier | Upstream license |
| --- | --- | --- |
| DINOv2 ViT-S/14 | `dinov2_vits14` | Apache License 2.0 |
| SigLIP 2 base patch16 NaFlex | `google/siglip2-base-patch16-naflex` | Apache License 2.0 |

- SigLIP 2 model card: https://huggingface.co/google/siglip2-base-patch16-naflex

The controlled scene, publication text, explorer, and figure-building code in this repository are project-authored materials. Consult the upstream projects for their model terms and documentation.
